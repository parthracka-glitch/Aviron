## ✦ Design & Motion System

- **Warm Luxury Palette:** Warm Alabaster/Ivory background with high-contrast near-black charcoal typography and refined champagne gold / bronze accents.
- **3D WebGL Canvas:** Interactive Three.js geometric polyhedron responding to pointer orientation and viewport scroll.
- **GSAP 3.12.5 & ScrollTrigger:**
  - Hero staggered entrance and scroll-linked depth exit.
  - Pinned horizontal portfolio gallery with touch/mobile fallback.
  - Masked line-by-line editorial typography reveals (`.mask-heading`).
  - Scroll-scrubbed bronze SVG progress line connecting process milestones.
  - Active step viewport glow highlighting timeline cards.
- **Atmospheric Micro-Interactions:**
  - Dynamic ambient pointer spotlight (`--mouse-x`, `--mouse-y`) following the cursor inside cards.
  - Bounded 3D perspective tilt (`[data-tilt]`).
  - Physics-based magnetic CTA buttons (`.magnetic`).
  - Strict reduced motion (`prefers-reduced-motion`) and touch device isolation.

## ✦ Tech Stack

- **Markup & Layout:** Semantic HTML5, CSS Grid, Flexbox, CSS Custom Properties (CSS variables).
- **Styling:** Vanilla CSS3 (zero Tailwind / CSS frameworks for maximal performance and zero build dependencies).
- **Logic & Motion:** Vanilla ES6+ JavaScript, [GSAP 3.12.5](https://greensock.com/gsap/), [ScrollTrigger](https://greensock.com/scrolltrigger/), and [Three.js r128](https://threejs.org/).
- **Zero Build Step:** Directly open `index.html` in any browser or serve via any static web server (Nginx, Apache, Vercel, Netlify, GitHub Pages).
